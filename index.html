    👋 How to play

    1. Choose players, rounds and prompt packs, then press Start game.
    2. A prompt appears. Everyone says (or writes) their funniest answer.
    3. The judge changes every round, in seat order (seat 1, then seat 2…). The judge doesn’t answer: they tap the name of the player with the best answer to give a point.
    4. Most points after the last round wins!

    🌐 Playing online

    • Pick Online, type your name, then make a room or enter a friend’s code (or scan their QR code).
    • Everyone waits in the lobby. The host presses Start game.
    • Every phone shows the same prompt and live scores. The judge’s phone lets them tap the winner, and the judge changes each round.
